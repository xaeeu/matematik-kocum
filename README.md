# Matematik Koçum

Temizden kurulan merkezi eğitim yönetim sistemi.

## Roller
- Baş Admin
- Öğretmen
- Öğrenci
- Veli

## Ana modüller
- Ders ve aylık takvim
- Çalışma saatleri ve otomatik aç/kapat kuralları
- Saat değişikliği talep/onay sistemi
- Koçluk
- Öğretmen değerlendirmeleri
- Deneme ve kazanım sınavları
- Ödev ve gelişim takibi
- Mobil/tablet uyumlu paneller
- Merkezi veri ve yetkilendirme

## Geliştirme ilkeleri
- Netlify bağımlılığı yoktur.
- Veriler merkezi backend üzerinden tutulacaktır.
- Geçmiş tarih/saat işlemleri kilitlidir.
- Ders çakışmaları ve kapalı saatler sunucu tarafında da doğrulanacaktır.
- Kullanıcı sadece yetkili olduğu veriye erişebilir.
